# Tamanna Dilshad — Portfolio

A personal portfolio built with plain **HTML, CSS and JavaScript**.

## Files
- `index.html` — portfolio content
- `style.css` — design and layout
- `script.js` — animations and interactions
- `assets/images/` — add your personal photos here

## Run locally
1. Open the `portfolio` folder in Visual Studio Code.
2. Open `index.html`.
3. Use the Live Server extension, or double-click `index.html` to view it in a browser.

## Add your photos
Place your own images in `assets/images/` with these names:
- `profile.jpg` — main profile photo
- `about.jpg` — About section photo

If you use another image format, update the matching image path in `index.html`.

## Update later
- Edit the About and introduction text in `index.html`.
- Add skills in the Skills section when you are ready.
- Add project cards in the Projects section when you have projects you want to showcase.
- GitHub profile: `https://github.com/tamannadilshadphul`
- Replace the email and LinkedIn placeholders with your real details when ready.

## Publish online
To make the portfolio publicly accessible, upload the `portfolio` folder to GitHub Pages, Netlify, or Vercel. This ZIP itself does not publish the website automatically.
