PUT YOUR IMAGES IN THIS FOLDER
==============================

Right now this folder is empty on purpose. The website shows pretty
pastel placeholders until you add your own pictures.

Use these exact file names (case matters on some systems):

  profile.jpg   -> big photo in the first screen (Hero)   (tall, about 4:5, e.g. 800 x 1000)
  about.jpg     -> photo in the About Me section          (square, e.g. 800 x 800)
  project1.jpg  -> screenshot of the Python Calculator    (wide, about 16:10, e.g. 1280 x 800)
  project2.jpg  -> screenshot of the Flag Design project  (wide, about 16:10, e.g. 1280 x 800)

Just drop the file in here and refresh the page. That's all!

Using .png or .webp instead? Open index.html, search for the file name
(for example "profile.jpg") and change the extension in the <img src="...">.

Tip: keep each image under ~500 KB so the site loads quickly.
